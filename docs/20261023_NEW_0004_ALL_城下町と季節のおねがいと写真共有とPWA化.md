## 変更内容

### 1. 世界「和風の城下町」（村 ＋ 星5）

- 見た目: 淡い水色の空、夕方は橙。季節あり（秋は紅葉）。鶴が6羽、羽ばたきながら空を周回する
- 専用の建物: 町家（8人）/ 天守閣（45人・幸福+12、町）/ 田んぼ（食料+25）/ 茶屋（コイン+12・幸福+3、村）/ 鳥居と灯籠（幸福+8。夜に灯籠が光る）/ 五重塔（幸福+20・コイン+5、都市）
- 専用の塗り: 白砂・朱の道（どちらも道扱い）
- 目標「城下町の建物を5つ」を追加。「すべての世界をひらく」は4世界に変更

### 2. 季節のおねがい

- 今日のおねがい3件のうち1件が、その季節だけの内容になる（集落以降）。報酬は星2
  - 春: 花を塗る / 夏: 池を作る / 秋: 食料の建物を建てる / 冬: 雪を塗る
- カードに「秋のおねがい」のタグを出す。カウントは塗り・建設のときに季節用のカウンタ（`flowerpaint` `pond` `farmbuild` `snowpaint`）を増やす

### 3. 島の写真（右のカメラボタン）

- 画面の3D部分だけを描き直して画像にし、下に帯（街の名前・時代 / 人口・世界・季節・連続日数 / キャッチコピー）を重ねる。横幅は最大1080px
- 「共有する」は Web Share API（iOS Safari・Android Chrome で共有シートが開く）。使えない端末では長押し保存か「保存」リンク
- 目標「島の写真を撮る」を追加（撮るたびに `life.photo` を数える）

### 4. PWA化

- `manifest.json`（standalone・縦向き・アイコン2種）、`<link rel="manifest">`、apple-touch-icon
- `sw.js`: 本体はネット優先（更新を拾う）で失敗時にキャッシュ。three.js や画像はキャッシュ優先。キャッシュ名 `hiraku-v1`（本体を大きく変えたら番号を上げる）
- 登録は http/https で開いたときだけ。Claude Artifact 上では登録しない（別ドメインのため）
- ホーム画面に追加すると全画面で起動し、2回目以降は圏外でも遊べる

- 管理番号: #0016
- 種類: ENH（機能改善）
- 対象: アプリ本体（APP）
- 作成日: 2026-11-10
- 関連: #0014, #0015

## 概要

v1.10。保存データを消して新規プレイで序盤を通し、初めての人がつまずく所と、v1.9 で足した機能の見えにくい所を直した。不具合（カードがスクロールできない）は #0015 に分けた。

## 対象ファイル

- `index.html` — 本体
- `about.html` — 目標の数の表記（40 → 50）
- `README.md` — 更新

## 変更内容

### 1. はじめの案内を短くした

- 変更前: 島の形を選んだ直後に、19項目の遊び方が1枚で出た（港・建物コード・ギャラリーなど、まだ使えない機能の説明まで並ぶ）
- 変更後: 「家を建てる・畑を作る・材料を集める・毎日すこしずつ」の4つだけを、アイコンつきのカードで出す（`showHelp`）。「くわしく見る」で全文へ
- くわしい遊び方（`showGuide`、設定の「遊び方」）は同じ19項目を「きほん・毎日コツコツ・季節と世界・合体・橋・島・住民・つくる・見せる・引き継ぐ」の6分類にして折りたたんだ（`GUIDE`、`<details class="gd">`）。最初は「きほん」だけ開いている

### 2. 「次にやること」のヒントを状況に合わせた（`nextHint`）

- 変更前: 家がいっぱいのとき、木材が0でも「住まいを増やそう」としか出なかった。集落になった直後は木材を使い切っているので、何をすればいいか分からない
- 変更後: 建てたいのに建てられない理由を先に案内する。木材が足りない（自分の土地に森がある → 伐採／ない → 森のある土地を買う／木こり小屋がある → 待つ）、コインが足りない（建物をタップ）、空き地がない（開拓）
- 集落からは、急がない案内を15秒ごとに交代で出す: 人口が頭打ち／合体を試そう（まだ1つも見つけていないとき）／手紙／港／この島の名物のヒント（合体を1つ見つけたあと）／次の時代。荒れ地のあいだは、人口の案内だけを出す

### 3. 時代が上がったときの一覧に名前をつけた（`eraUp`）

- 変更前: 新しく建てられる建物が絵だけで並び、スマホでは名前が分からなかった（`title` 属性だけ）。ほかの世界の建物と、季節ちがいの限定建物も混ざっていた
- 変更後: 絵の下に名前を出す。いまの世界・いまの季節で建てられるものだけにした

### 4. 住民どうしの会話を、見えている所で起こす

- 変更前: 会話の2人を島全体から選んでいたので、画面の外で始まることが多く、目標「会話を3回聞く」も見ないうちに進んだ。吹き出しが上のバーや右のボタンに重なることもあった
- 変更後: 画面の中央寄り（左右70px・上150px・下のパネルより上）に見えている住民だけから選ぶ。カードを開いているあいだは始めない。吹き出しは、住民が画面の端やバーの下に入ったら隠す（タップの吹き出しも同じ、`placeBubble` / `inView`）
- 2人の選び方を、マスどうしの距離から実際の位置の距離（0.35〜1.3マス）に変えた。会話が始まると、その場で立ち止まる（マスの中心へ飛ばない）

### 5. 図鑑を4つに分けた

- 55種が1列に並んでいたのを「この島の名物（島の種類）・きほんの合体・世界ごとの合体・ほかの島の名物」に分け、それぞれに見つけた数を出して折りたためるようにした。この島の名物ときほんは最初から開いている。世界ごとは、のどかな島以外にいるときに開く

### 6. そのほか

- 鉱山町（岩の島の名物）は、もとの石切り場と同じく石を生む（隣の岩1つにつき +0.2/秒）。合体したら石の収入が消える、ということが起きないようにした
- 紹介ページの「40の目標」を、いまの数の50に直した

確認したこと（ヘッドレスの Chrome、375×812 と 375×667、音は出さない設定）:

- 新規プレイで、島の形 → 4つの案内（カードは画面内、ボタンが見える）→「くわしく見る」で6分類19項目 → 閉じる
- 家3・畑2で集落になり、一覧に 家・石切り場・市場・風車・街灯・公園・収穫祭のやぐら が名前つきで出る
- ヒント: 木材0で「伐採で森を切ろう」、森を切り尽くすと「森のある土地を買って」、コイン不足で「建物をタップ」、足りていれば「住まいを増やそう」。集落でごほうびを受け取ったあと、合体の案内・手紙・次の時代が交代で出る。合体を1つ見つけると、名物のヒントに入れ替わる
- 会話が画面内の2人で始まり、カメラを動かして画面外にすると吹き出しが隠れ、戻すと出る
- 図鑑が 2 / 29 / 16 / 8 に分かれる。鉱山町の石が +0.4/秒（岩2つ）
- 指のスクロールでカードが動き、固定された「閉じる」を指でタップして閉じられる。エディタのマス目の上ではスクロールしない
- エラーなし

アプリ内のブラウザは、パネルが隠れているあいだ描画の更新（requestAnimationFrame）が止まり、ゲームが進まない。今回は進行が要る確認をヘッドレスの Chrome で行った。

## 変更内容

### 1. 島の形（新規スタート時）

- 最初に「丸い島 / 三日月の島 / 群島」を選ぶ画面を出す。`S.shape` に保存し、あとから変えられない
- 三日月: 右上に入り江（第2の円で高さを削る）。群島: 6つの中心からの距離で小島を作り、中央の島は必ず残す。初期の所有地（中央 6×6）は共通

### 2. 空中都市（都市 ＋ 星10）

- 見た目: 水色の空、海底を雲色にして「雲の上に浮かぶ島」に見せる。大きな白い雲がゆっくり流れ、飛行船が4隻周回する。季節あり
- 専用の建物: 雲の家(10人) / 浮遊宮殿(55人・幸福+12、都市。浮かぶ) / 雲の畑(食料+32) / 風の発電塔(コイン+22、町。羽が回る) / 虹の橋(幸福+12) / 飛行船ドック(幸福+18・コイン+8、都市)
- 専用の塗り: 雲の石畳（道）・虹色（花扱い）
- 「すべての世界をひらく」の目標は5世界に

### 3. 大型建物（2×2マス）と回転

| 建物 | 条件 | 費用 | 効果 |
|---|---|---|---|
| 駅 | 町 | コイン3500・木200・石400 | コイン+30/秒。電車が行き来する |
| ショッピングモール | 都市 | コイン7000・木200・石700 | コイン+40/秒、幸福+5 |
| スタジアム | 都市 | コイン8000・木400・石900 | 幸福+30、コイン+10/秒。夜に照明 |

- 置くときは左上のマスをタップ。4マスすべてが自分の土地で、建物・水・森・岩がないこと
- 左上以外の3マスは `b:'__big'` と `ref:（左上の番号）` を持ち、情報・撤去・強化・回転は左上に転送する。撤去で4マスとも空く
- 「回転」ツール（開拓タブ）: 建物をタップすると90°ずつ向きが変わる（`tl.r`）。見た目だけで効果は変わらない
- 保存形式: タイル配列に `r`（向き）と `ref` を追加（旧データは0/なし扱い）

v1.8。#0009 の「次に広げるなら」3件をすべて実装した。合体ルールを21種足して45種に、じぶんの建物を文字列で渡せる建物コード、島コードを投稿して人の島を見学し合える「みんなの島ギャラリー」（紹介ページ）。

## 変更内容

### 1. 合体ルールの追加（24 → 45種）

- 一般: 果樹園（畑＋さくら）、温泉（ベンチ＋池2＋街灯）、夜市（市場＋街灯2＋ベンチ）、図書館（学校＋ベンチ2＋花壇）、お祭り広場（神社＋街灯2＋花の塗り2）、高層街（マンション3＋道2）、リゾート（公園＋海3＋ベンチ）、酒蔵（風車＋畑2＋池）、風車群（風車3）、大きな港（港＋市場＋灯台）、学園都市（学校＋図書館＋公園。図書館を見つけたあとの二段階）
- 世界: 妖精の湖・魔法の門（魔法の国）、棚田・参道（城下町）、研究都市・メガタワー（未来都市）、海藻の森・珊瑚礁（海底都市）、風の農園・虹の回廊（空中都市）
- メッシュは既存の建物を縮小して組み合わせる `sub()` を中心に、温泉の湯気・魔法の門の回る輪などの小さなアニメを追加
- 目標「合体を25種類見つける」を追加

### 2. 建物コード

- エディタの「作った建物」一覧に「コード」ボタン。`HIRAKUB1.` ＋ Base64（名前・種類・ボクセル384文字）の文字列を表示・コピー・共有
- 「建物コードから作る」で貼り付けると、新しいじぶんの建物として追加（12個の上限は同じ）。形式と文字種を検証してから受け付ける

### 3. みんなの島ギャラリー

- 島コードの画面に「みんなの島ギャラリーに投稿」。島コードをクリップボードにコピーしてから、GitHub の Issue 作成ページ（`labels=island`、タイトルは「〇〇島（都市・人口N）」、本文に貼り付けの案内）を開く。投稿には GitHub アカウントが要る
- `about.html` の「みんなの島」: GitHub API（`issues?labels=island`）を読み、本文から `HIRAKU1.…` の島コードだけを取り出してカードに並べる（タイトル・投稿者・日付・ひとこと・「見学する」）。見学リンクは `index.html#visit=コード`。投稿内容はエスケープして表示し、コード以外は信用しない。読めないときは案内文
- ゲーム本体は引き続き通信なし。ギャラリーの読み込みは紹介ページ（Web）だけで行う

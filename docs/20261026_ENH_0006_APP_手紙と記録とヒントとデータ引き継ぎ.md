## 概要

遊びやすさと続けやすさの改善。画面下に「次にやること」を状況から出すヒント、住民からの手紙（日替わりの要望）、記録タブと称号、機種変更用のデータ書き出し／読み込み、重い端末で影を自動OFFにする仕組みを追加した。

## 対象ファイル

- `index.html` — すべてこのファイル内（約133KB）
- `README.md` — 更新

## 変更内容

### 1. 次にやることヒント

ツール未選択（えらぶ）のとき、画面下のヒント欄が状況に応じて変わる。順番に判定: 家がない→伐採か小さな家 / 食料が上限→畑・風車 / 家がいっぱい→住まい / 幸福が低い→飾り / 受け取れるごほうびがある / 手紙の内容 / 次の時代の条件 / 塗って遊ぼう。1.2秒ごとに見直す。

### 2. 住民からの手紙

- 15通の要望（公園がほしい、街灯を3本、道を10マス、池、花8マス、噴水、学校、市場、風車、森5マス、幸福70%、ベンチ2つ、家3軒、銅像、さくら）。時代で出る手紙が変わり、すでに満たしているものは出ない
- 1日1通。かなえると「今日」タブで受け取れる（`max(60, 収入/秒×60)` コイン＋星1）。受け取り済みなら翌日に次の手紙
- 目標「住民の手紙を3通かなえる」を追加（`life.letter`）

### 3. 記録タブと称号

- 「毎日コツコツ」画面に3つ目のタブ「記録」。遊んだ日数・最高人口・達成した目標・ひらいた世界・建てた回数・伐採・塗り・開拓・強化・写真・連続ログイン・時代
- 称号は達成した目標の数で上がる: 開拓者(0) → 村の世話役(5) → 町づくりの名人(10) → 都市の設計者(18) → 世界をひらく者(28) → 伝説の島主(38)。写真の帯にも入る

### 4. データの書き出し／読み込み（設定）

- 書き出し: 保存データを `HIRAKU1.` ＋ Base64 の文字列にして表示。コピーと共有ができる
- 読み込み: 文字列を貼り付けて「読み込んで上書き」。形式を検証してから保存し、再読み込みする
- iOS 版と Web 版のあいだでも移せる

### 5. 影の自動OFF

起動後8秒の平均フレームレートが28未満なら影をOFFにして知らせる。設定で手動にした場合（`hiraku.shadow` が保存済み）は触らない。

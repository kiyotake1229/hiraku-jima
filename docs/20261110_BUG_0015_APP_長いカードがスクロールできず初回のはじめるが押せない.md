# 長いカードがスクロールできず、初回の「はじめる」が押せない不具合の修正

- 管理番号: #0015
- 種類: BUG（バグ修正）
- 対象: アプリ本体（APP）
- 作成日: 2026-11-10
- 関連: #0008, #0009, #0014

## 概要

最初から遊び直して見つけた不具合。画面の上に出るカード（遊び方・毎日コツコツ・建物エディタなど）が画面より縦に長いと、上下がはみ出したままスクロールできなかった。スマホ（高さ812px）では、初回の遊び方カードが1372pxあり、「はじめる」ボタンが画面の下に隠れて押せなかった。バッジのタブは4411pxで、タブも「閉じる」も画面外だった。

遊び方の項目が増えた v1.7（#0009、2026-11-06）以降、スマホで初めて開いた人はゲームを始められない状態だった。

## 対象ファイル

- `index.html`

## 変更内容

### 原因

- `#ov`（全画面の暗幕）は `display:flex; align-items:center` でカードを中央に置くだけで、カード（`.card`）に高さの上限もスクロールもなかった。中身が画面より長いと、上下に同じだけはみ出す
- 目標の一覧だけは `.list` に `max-height:50vh` があり、ほかの長い内容（遊び方・図鑑・バッジ・記録・エディタ）には無かった

### 修正

- `.card` に `max-height:100%; overflow-y:auto; overscroll-behavior:contain` を足し、カードの中でスクロールできるようにした。`#ov` の余白はセーフエリア（ノッチ・ホームバー）を足した値にした
- 閉じるボタンの行（`.card>.row:last-child`）を `position:sticky` で下に固定し、どこまでスクロールしても押せるようにした。毎日コツコツのタブ（`.ovtabs`）は上に固定した
  - 注意: スクロールする箱に padding があると、sticky の基準は padding の内側になる。`top:0` / `bottom:0` では padding の幅（22px）だけすき間ができて、裏の内容が透ける。`top:-22px` / `bottom:-22px` にして、行のほうに同じ幅の padding を持たせた
- 建物エディタは「作る / やめる」の行を下に固定し（`.row.stk`）、いちばん下の「建物コードから作る」の行は固定しない（`.row.ns`）
- `overlay()` は、別の画面を開いたときにスクロールを先頭に戻す。同じ画面の描き直し（ごほうびの受け取りなど）では位置を保つ。見出しと選択中のタブで同じ画面かどうかを判断する

確認したこと（375×812、音は消して実施）: 遊び方（中身1360px）・バッジ（4394px）・建物エディタ（929px）のカードが画面内（上14px〜下798px）に収まり、中でスクロールできる。どのスクロール位置でも「閉じる」が同じ場所に見えていて、その位置をタップすると実際にボタンに当たる。タブはスクロールすると上に固定され、タブを切り替えると先頭に戻る。設定・島をわたる・世界など短いカードの見た目は変わらない。

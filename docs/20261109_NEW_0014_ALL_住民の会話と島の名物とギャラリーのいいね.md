## 変更内容

### 1. 住民どうしの会話

- 住民が2人以上いるとき、8〜22秒おきに、同じマスか隣のマスにいる2人を選んで会話を始める。2人は立ち止まって向き合い、先に1人目（淡い黄色の小さな吹き出し `#cb1`）、2.6秒後に2人目（`#cb2`）が話す。5.8秒で終わり、また歩き出す
- 台詞は3層。共通16組（`CHATS`）、性格ごと各2組（`TRAIT_CHATS`、1人目の性格で選ぶ）、状況（`CHAT_CTX`: 夜・幸福度が低い・冬・春・合体を見つけた・名物のある島・島が2つ以上）。`{you}` に相手の名前、`{isle}` `{world}` `{pop}` `{kindn}` を差し込む
- 会話中の住民はタップでの会話（#0009）もそのまま使える。島をわたると会話は打ち切る。見学中は数えない
- 目標「住民どうしの会話を3回聞く」（`chat3`）を追加。`S.life.chat` で数える
- 実装上の注意: 住民は目的のマスに着いた同じフレームで次のマスへ歩き出すので、「立ち止まっている2人」は存在しない。歩行の進み `t` が 0.6 以上の2人を目的マスどうしの距離で選び、会話開始時にマスの中心へ置いて止める（`u.pause`）

### 2. 島ごとの名物（合体10種、合計55種）

- `FUSIONS` に `kind` を持つルールを追加。`fusionMatch` で現在の島の種類（`curKind()`）が一致するときだけ合体する。材料に地形を使えるようにした（`beach` 砂浜 `t==='s'`、`forest` 森、`rock` 岩、`snowp` 雪の塗り）
- みどりの島: 牧場（畑＋畑＋公園）、キャンプ場（ベンチ＋池＋森）／深い森の島: 森のロッジ（小さな家＋森2＋街灯）、ツリーハウス村（公園＋森3）／岩の島: 鉱山町（石切り場＋石切り場＋小さな家2）、岩山の砦（家＋岩2＋街灯）／雪の島: かまくら村（小さな家＋小さな家＋雪の塗り3）、雪まつり（銅像＋街灯2＋雪の塗り2）／砂の島: オアシス（公園＋池2＋砂浜）、砂の遺跡（神社＋砂浜2＋石切り場）
- メッシュは `sub()` と基本形で作り、キャンプ場のたき火・かまくらの明かりに小さなアニメ
- 図鑑のヒントは「雪の島: …」で始め、見つけたあとのレシピに「（雪の島だけ）」を付ける。発見カードにも「〇〇の島の名物です」。島をわたる画面の各島に「名物: 牧場・？？？」、新しい島を見つけたときに名物の数を案内
- 目標「島の名物を見つける」「島の名物を3つ見つける」を追加。住民の台詞に名物の話を追加

### 3. ギャラリーのいいね

- `about.html` のカードにハートと数。数は、その Issue についた GitHub のリアクション（heart・+1・hooray）の合計。ハートを押すと Issue が開き、GitHub 上でリアクションできる（アカウントが要る）
- 「新しい順」「いいね順」の並べ替えボタンと件数表示
- Issue 本文は引き続きエスケープし、リンク先は `https://github.com/` で始まるものだけ使う。ゲーム本体は通信なしのまま

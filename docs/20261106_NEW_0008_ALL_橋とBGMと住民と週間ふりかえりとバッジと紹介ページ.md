## 変更内容

### 1. 橋（開拓タブ、集落から）

- 自分の土地か橋に接した**海**のマスに、木材15・石5 で橋をかける。チェーン状につなげられる
- 橋のマスは `t:'w'` のまま `own:true, b:'bridge'`。向きは左右に土地か橋があれば横、なければ縦に自動で決まる（「回転」で変更可）
- 橋の先の土地は「開拓」で買える（隣接判定に橋が含まれる）ので、群島を埋め立てなしでつなげる
- 住民は橋を歩いて渡る（`walkable` と道の優先に橋を追加）。家の隣の橋は道と同じ扱い（人口+25%）
- 撤去すると海に戻る（`own:false`）。橋の上の埋め立て・強化は不可。建物の数（目標の「建物を○棟」）には数えない
- 目標「橋を5マスかける」（`S.life.bridge`）を追加。目標は40件に

### 2. BGM（設定でON/OFF、既定ON）

- WebAudio でその場で生成するループ。音源ファイルなし。世界ごとに音階・テンポ・音色・ローパスが変わる（`BGM_DEF`: のどかな島=メジャーペンタ、魔法=和声的短音階風、城下町=都節、未来=マイナーペンタ+矩形波、海底=ゆっくり低域、空中=高域トライアングル）
- 64ステップのメロディは世界名から決まる擬似乱数で生成し、同じ世界では毎回同じ曲になる。8ステップごとにベース、16ステップごとにパッド
- 毎フレーム `bgmTick()` が 0.5 秒先まで予約する。画面を離れて戻ったときは `bgm.next` を現在に寄せて、まとめて鳴らさない
- 効果音ボタン（右の音ボタン）でOFFにすると BGM も止まる。設定に BGM だけのスイッチ（`hiraku.bgm`）
- ブラウザ内蔵の確認環境では AudioContext の時計が進まないため、実際の鳴り方は実機で確認すること

### 3. 世界ごとの住民

- `makeWalker()` が `T.k` を見て姿を変える: 未来都市=ロボット（箱の体・アンテナ）、海底=潜水服（ガラスのヘルメット・ボンベ）、魔法の国=魔法使い（とんがり帽子）、城下町=着物（帯・お団子髪）、空中都市=天使（羽と光る輪）
- 世界を切り替えると住民を全員消して出し直す（`applyTheme`）

### 4. 先週のふりかえり（週間レビュー）

- `S.wk` に週の始まりの記録（人口・建てた回数・塗った数・開拓・目標数・遊んだ日数）。`newDay()` で月曜になったとき、または7日以上たっていたら `S.review` を作って記録を取り直す
- 「今日」タブの先頭にカードで表示（人口の増減・建てた・塗った・開拓・達成した目標・遊んだ日 ＋ ひとこと）。3日以上遊んでいれば星1。閉じると「記録」タブに残る
- 旧データでは初回起動時に `S.wk` を作る

### 5. バッジ

- 「毎日コツコツ」に4つ目のタブ「バッジ」。40の目標を4列のバッジで並べ、達成は金色、未達成はグレーで進み具合のバー。タップで進み具合を表示
- アイコンは目標IDの接頭辞で選ぶ（`GOAL_ICONS`）

### 6. ご意見リンク

- 設定に「ご意見・不具合を送る」ボタン。GitHub の Issue 作成ページ（https://github.com/kiyotake1229/hiraku-jima/issues/new）を新しいタブで開く。Google フォームにしたいときは `showSettings` 内の URL を差し替える

### 7. 紹介ページ `about.html`

- GitHub Pages の https://kiyotake1229.github.io/hiraku-jima/about.html
- 内容: キャッチコピーとプレイボタン、特徴6つ、スクリーンショット（横スクロール）、6つの世界、はじめかた、技術メモ（three.js・WebAudio・PWA・Capacitor）、GitHub へのリンク。フリーランス営業のポートフォリオとして見せる想定
- 単一 HTML、外部依存なし。スクロールでカードが順に出る

### 8. App Store スクリーンショット

- headless Chrome（puppeteer-core）で、見栄えのする街を自動生成して撮影。実機ではなく Web 版を撮っているので、UI は iOS 版と同じ
- サイズ: 6.7インチ 1290×2796（`67_*`）、6.5インチ 1284×2778（`65_*`）、5.5インチ 1242×2208（`55_*`）
- 場面: 1 のどかな島の都市 / 2 未来都市 / 3 空中都市 / 4 魔法の国 / 5 バッジ画面
- App Store Connect にそのまま上げられる。撮り直すときは同じ手順（街の生成スクリプトは docs に残していない。必要なら `window.__hiraku` を使ってブラウザで作り直す）

### 9. その他

- `README.md`: 「4つの世界」「目標30件」の数字を直し、遊び方 18〜21 とファイル構成を追加
- iOS: `npm install → npm run sync → node_modules 削除` を実施。Web 資産の同期は成功、`pod install` はこの Mac に Xcode がないため失敗（岩崎さんの Mac で `npx cap sync ios` をやり直す。手順書どおり）

## 概要

スマホ1画面で遊ぶ3Dの土地開拓・都市育成ゲーム。森を切り開いて建物を建て、人口で「荒れ地→集落→村→町→都市→大都市」と発展する。地面を自由に塗って模様の世界を作る「塗る」モードを持つ。2026-10-21 に初版を作成し、Web版として遊べる状態。以後の変更は #0002 以降に記録する。

## 対象ファイル

パスは `土地開拓ゲーム/` からの相対パス。

- `index.html` — アプリ本体。HTML・CSS・JavaScript を1ファイルに収める（約75KB）
- `icon.svg` — アイコン元データ
- `README.md` — アプリの状態・遊び方・残作業

## 仕様

### 技術

- three.js r128 を cdnjs から `<script>` で読む（モジュール不使用。Artifact の CSP でも動く）
- マップは 32×32 タイル。値ノイズと中心からの距離で島の形を生成し、seed は保存する
- 描画: 地面・水・木・岩・花は `InstancedMesh`（タイル数ぶんの固定インスタンス。不要なものはスケール0）。建物は Box/Cone/Cylinder を組んだ `Group` を1タイル1つ
- 影: `PCFSoftShadowMap` 1024px。設定でOFFにできる（`hiraku.shadow`）
- カメラ: 透視投影。1本指ドラッグで地面上の点を固定して移動、2本指でズーム（6〜44）、回転ボタンで90°ずつ回転
- 昼夜: 240秒で1周。空の色・太陽の強さ・窓と街灯の発光を変える
- 音: WebAudio でその場で生成（ファイルなし）。消音は右の音ボタンまたは設定（`hiraku.snd`）
- 触覚: `navigator.vibrate`

### タイル

`{t, own, b, p, v}`
- `t`: 地形。`g`草 / `w`水 / `s`砂 / `r`岩 / `f`森
- `own`: 自分の土地か。中心 6×6 が初期所有。未所有は暗く描く
- `b`: 建物キー（下表）または null
- `p`: 塗りキー（草・濃い草・砂・道・石畳・レンガ・花6色・雪・池）または null
- `v`: 0〜1 の乱数。色の揺らぎ・木の大きさ・家の壁と屋根の色に使う

### 行動（開拓タブ）

| 行動 | 条件 | 効果 |
|---|---|---|
| えらぶ | — | タップで情報パネル。所有する建物をタップすると `max(1, 収入/秒×4)` コイン |
| 開拓 | 未所有・水以外・所有地に4近傍で隣接 | `floor(10×1.07^購入数 + 購入数×2)` コイン |
| 伐採 | 所有地の森 | 木材 +4〜7、草地になる |
| 採掘 | 所有地の岩 | 石 +3〜6、草地になる |
| 木を植える | 所有地の草・砂、建物なし | 5コイン、森になる |
| 埋め立て | 村以降、水（海は所有地に隣接、池は所有地） | 石 40、砂地になり所有地になる |
| 撤去 | 建物あり | 建設費の半額が戻る |

### 経済

- 住居合計 = Σ住居（道に4近傍で接する家は ×1.25）。食料 = 6 + Σ食料
- 人口の目標 = min(住居, 食料)。人口は 1.2 秒に 1 人ずつ目標へ近づく
- 幸福 = 50 + Σ建物の幸福 + min(20, 花タイル数×0.5)。0〜100 に収める
- コイン/秒 = 人口 × 0.15 × (0.5 + 幸福/100) + Σ建物のコイン
- 時代は人口のしきい値（0 / 6 / 20 / 60 / 150 / 400）で上がる。下がらない。上がったときに演出と解放一覧を表示
- 再開時: 前回保存からの経過（最大6時間）× 収入 × 0.5 を付与して「おかえり」表示

### 塗り（塗るタブ）

- 所有地の海以外に塗れる。無料（池だけ石10、集落以降、建物なし）
- 道・石畳・レンガは「道」扱い（家の人口ボーナス）。花6色は幸福に寄与し、森に塗ると草地になる
- 「なぞって塗る」ON で1本指のドラッグが塗りになる（移動は2本指）
- 「塗りを消す」で元の地面に戻す

### 保存

- キー `hiraku.v1`。`{s: 状態, tl: タイル配列}`。タイルは `[t, own, b, p, v×1000]` の配列で圧縮
- 5秒ごと、画面を隠したとき、ページを閉じるときに保存。`localStorage` が使えない環境でも落ちない
- 設定: `hiraku.snd`（音）、`hiraku.shadow`（影）

### 画面

- 上: 資源バー（コイン・木材・石・食料・人口/住居・幸福）と時代バッジ＋次の時代までの進捗
- 右: 回転 / 中心へ / 音 / 設定
- 下: タブ（開拓・住まい・仕事・飾り・塗る）と横スクロールのカード。カードの画像は起動時に three.js で描画して生成（絵文字不使用）
- 情報パネル: えらぶモードでタイルをタップすると表示。状況に応じた操作ボタンを出す
- 設定: 音・影の切り替え、遊び方、最初から（確認あり）

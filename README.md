# ひらく島 — 毎日コツコツ育てる街

森を切り開いて家を建て、集落 → 村 → 町 → 都市 → 大都市へ。地面を自由に塗って、自分だけの模様の世界を作る3D箱庭ゲーム。スマホの一画面で完結し、毎日少しずつ遊んで育てる。

## 遊び方

1. **開拓** タブ: 暗い土地を買い足す。森を「伐採」すると木材、岩を「採掘」すると石が手に入る
2. **住まい** タブ: 家を建てると人が住む。**仕事** タブの畑で食料を増やすと、食料の分だけ人口が増える
3. 人口が増えると時代が進み、新しい建物が増える（集落 6人 / 村 20人 / 町 60人 / 都市 150人 / 大都市 400人）
4. 人口 × 幸福度でコインが毎秒たまる。建物をタップしてもコインがもらえる
5. **飾り** で幸福度を上げる。**道** に面した家は人口 +25%
6. **塗る** タブで地面に色を塗る（草・砂・道・石畳・レンガ・花6色・雪・池）。「なぞって塗る」をONにすると指でなぞって一気に塗れる
7. 村になると水辺を「埋め立て」して島を広げられる
8. **毎日コツコツ**（右上のチェックリスト）: 毎日開くと連続ログインボーナス。日替わりの「今日のおねがい」3件と、長期の「目標」40件を達成すると **星** がもらえる
9. 星は さくらの木・灯台・神社・気球 と交換。建物は「強化」で Lv3 まで育ち、効果が最大 2.4 倍
10. 隣接ボーナス: 家の隣に飾りで+10%、畑の隣に池か風車で食料×1.5、市場の隣の家1軒ごとにコイン+0.3/秒。幸福度が50%を切ると人が住み着きにくくなる
11. **季節**（右の地球ボタン）: 日付で春夏秋冬が変わり、木や地面の色、舞うもの（花びら・ホタル・落ち葉・雪）が変わる。季節限定の建物があり、季節は固定もできる
12. **世界**: 星で「魔法の国」「和風の城下町」「未来都市」「海底都市」「空中都市」をひらける。空・水・木の色が変わり、空飛ぶ車や魚が現れ、専用の建物と塗りが使える。ひらいた世界は自由に行き来でき、建てたものは残る
13. 季節ごとの**特別なおねがい**（春: 花を塗る、夏: 池を作る、秋: 食料の建物、冬: 雪を塗る）は星2
14. カメラボタンで**島の写真**を撮り、名前・人口・世界の帯つきで共有・保存できる
15. 画面下に**次にやること**のヒントが出る。**住民からの手紙**（1日1通の要望）をかなえると星。「記録」タブに遊んだ日数や最高人口、**称号**（目標の達成数で上がる）
16. 設定の**データを書き出す／読み込む**で、機種変更や iOS 版への引き継ぎができる。重い端末では影が自動でOFFになる
17. 最初に**島の形**（丸い島・三日月・群島）を選べる。駅・ショッピングモール・スタジアムは**2×2マスの大型建物**。「回転」で建物の向きを変えられる
18. 集落になると海に**橋**（木材15・石5）をかけられる。橋をつなげれば隣の島を開拓でき、住民も渡る。橋に面した家は道と同じ+25%
19. **BGM**は世界ごとに違う曲（端末内で生成、音源ファイルなし。設定でOFF）。住民の姿も世界ごとに変わる（ロボット・潜水服・魔法使い・着物・天使）
20. 月曜になると**先週のふりかえり**（人口の増え方・建てた数・遊んだ日）が届き、3日以上遊んでいれば星1。達成した目標は**バッジ**タブにコレクションとして並ぶ
21. 設定の「ご意見・不具合を送る」から GitHub の Issue に意見を送れる
22. **合体**: 建物のまわりに決まった組み合わせがそろうと新しいものに変わる（小さな家3軒→長屋、家3軒＋公園→団地、灯台を海ぎわに→漁港 など45種。世界ごとの合体もある）。見つけたものは**図鑑**（バッジタブ）に載り、未発見はヒントだけ出る
23. **島コード**（設定）: 島をまるごと文字列にして保存・共有できる。人のコードを「見学」すると、その島を歩いて見られる（自分の島は変わらない）。`#visit=コード` のリンクでも開ける
24. **航海**: 村になったら海ぎわに**港**を建て、右の船ボタンから新しい島を探せる（星とコイン）。島は何個でも増やせ、みどり・深い森・岩・雪・砂の5種類×3つの形。コイン・材料・星は共通で、離れた島の人口と収入も入る
25. 歩いている**住民**をタップすると話せる。24人に名前と性格（のんびり・おしゃべり・はたらきもの など8種）があり、島の状態で話が変わる
26. **じぶんの建物**（住まい・仕事・飾りタブ）: 8×8×6 のブロックを積んで建物をデザインし、名前をつけて建てられる（12個まで）。島コードに含まれるので見学した人にも見える。**建物コード**で建物だけを人に渡せる
27. **みんなの島ギャラリー**: 島コードの画面から GitHub の Issue に投稿すると、[紹介ページ](https://kiyotake1229.github.io/hiraku-jima/about.html#gallery) に並び、だれでも見学できる（投稿には GitHub アカウントが必要。ゲーム本体は通信なしのまま）

操作: 1本指ドラッグで移動、2本指でズーム、右の回転ボタンで視点を90°回す。昼夜が4分で1周し、夜は窓と街灯が光る。アプリを閉じている間も最大6時間ぶん（半分の効率）資源がたまる。

## iOS版

`ios-app/` に Capacitor 7 のプロジェクトがある（Bundle ID `work.ltv.hiraku`）。three.js を同梱して完全オフライン、触覚フィードバックとローカル通知（翌朝9時の「今日のおねがい」）がネイティブで動く。ビルドと申請の手順は [ios-app/岩崎さんへの引き渡し手順.md](ios-app/岩崎さんへの引き渡し手順.md)。`node_modules/` は削除してあるので `npm install` から。

App Store 用の申告として、プライバシーマニフェスト（`ios-app/ios/App/App/PrivacyInfo.xcprivacy`）と暗号化の申告（`ITSAppUsesNonExemptEncryption = NO`）を入れてある。push すると GitHub Actions（`.github/workflows/ios-build.yml`、Xcode 26 に固定）が署名なしでビルドし、これらがアプリに入っていることと、three.js が同梱されていることを確かめる（docs #0010）。

## ローカルで確認する

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

ブラウザで http://localhost:8765/index.html を開く。`file://` で直接開くと localStorage が使えない環境があるため、サーバー経由を推奨。
